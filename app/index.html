Modern DevOps CI/CD Pipeline

This project demonstrates a complete CI/CD workflow using GitHub, Jenkins, SonarQube, Trivy, Docker, Kubernetes, Prometheus, and Grafana.

GitHub

Source code is stored in GitHub. Every code push triggers the CI/CD pipeline automatically using webhooks.

Jenkins

Jenkins builds the project, executes automated tasks, and manages the deployment pipeline.

SonarQube

Performs static code analysis to identify bugs, vulnerabilities, and maintain code quality.

Trivy

Scans Docker images for security vulnerabilities before deployment.

Docker

Packages the application into portable containers for consistent execution across environments.

Kubernetes

Deploys, scales, and manages Docker containers with high availability.

Prometheus

Collects metrics from applications and Kubernetes clusters for performance monitoring.

Grafana

Displays real-time dashboards for infrastructure health, application performance, and monitoring.

End-to-End CI/CD Pipeline | GitHub → Jenkins → SonarQube → Trivy → Docker → Kubernetes → Prometheus → Grafana
